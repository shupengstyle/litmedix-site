PRIVACY POLICY

隐私政策

PubMed 文献检索增强与本地笔记工具

LitMedix 不要求用户注册账号，也不运营用于收集用户笔记或用户导入期刊指标数据的远程服务器。

我们处理的数据

为了提供用户主动使用的功能，LitMedix 会在设备本地处理以下数据：

  • 当前 PubMed 页面中的公开文献信息，例如标题、期刊名称、PMID、DOI、发表年份和文献类型；
  • 用户创建的文献笔记和标签；
  • 用户自行导入的期刊指标及历年影响因子数据；
  • 筛选条件、界面位置、功能开关等偏好设置；
  • 用户主动选择的笔记备份文件夹授权。

数据存储

上述数据默认保存在用户浏览器或用户主动选择的本地文件夹中。LitMedix 不会将笔记、标签或用户导入的期刊指标数据上传至开发者服务器。

网络请求

LitMedix 仅访问 PubMed 和 NCBI E-utilities，以打开用户请求的 PubMed 页面并获取公开文献元数据。请求可能包含公开的 PMID 或 DOI，不包含用户笔记、标签或用户导入的期刊指标文件。

数据分享与商业用途

LitMedix 不出售用户数据，不向第三方共享用户数据，不将用户数据用于个性化广告、信用评估或其他与插件单一用途无关的用途，也不允许开发者人工读取用户的本地笔记。

用户控制与删除

用户可以在插件中编辑或删除笔记、清除自行导入的数据、导入或导出备份。用户也可以通过清除扩展程序数据或卸载 LitMedix 删除浏览器中的本地数据。已由用户导出至本地文件夹的文件需由用户自行删除。

第三方服务

用户访问 PubMed 或 NCBI 服务时，同时受相应第三方服务的隐私政策与使用条款约束。

Chrome Web Store 有限使用声明

LitMedix 对从 Chrome API 获得的信息的使用将遵守 Chrome Web Store 用户数据政策，包括有限使用要求。

政策变更与联系

本政策如有重要变更，将更新本页面及生效日期。有关隐私问题，用户可通过 LitMedix 的 Chrome Web Store 商品页面联系开发者。
